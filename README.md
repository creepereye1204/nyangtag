# 냥태그 🐾

고양이 밈 GIF로 하는 2:2 얼음땡 술래잡기. 브라우저만 있으면 PC·폰 다 됩니다.

## 플레이
- **방 만들기** → 4자리 코드나 초대 링크를 친구한테 보내기 → 친구는 코드 입력 후 **참가**
- 로비에서 치즈팀/고등어팀 고르기, 빈 자리는 봇이 채움 (최대 4명)
- **봇이랑 연습하기**로 혼자도 가능

## 규칙
- 술래팀이 닿으면 얼음, 같은 팀이 닿아 주면 땡
- 도망팀 둘이 동시에 얼면 술래팀 승, 60초 버티면 도망팀 승
- 풀숲·이불·상자·커튼·식탁 밑에 숨으면 상대에게 안 보임 (가까이 오면 들킴)
- 술래는 5초 뒤 출발, 4라운드 동안 술래 교대

## 조작
- PC: WASD / 방향키 이동, Space / Shift 대시
- 폰: 왼쪽 화면 드래그 = 조이스틱, 오른쪽 대시 버튼

## 고양이
그림 고양이 4종, GIPHY 고양이 밈 GIF, 또는 아무 GIF 주소나 붙여 넣기. 고른 GIF는 같은 방 친구들한테도 보입니다.

## 구조
- `core.js` 맵·규칙·봇(A* 길찾기) — 방장 브라우저가 시뮬레이션
- `main.js` 화면·입력·로비·온라인 (PeerJS/WebRTC, 서버 없음)
- 손님은 자기 고양이를 직접 움직여 위치를 보내고, 방장이 얼음/땡 판정과 봇을 맡습니다.

일부 회사망·통신사망에서는 WebRTC 연결이 안 될 수 있어요 (PeerJS 기본 TURN 서버 사용).
