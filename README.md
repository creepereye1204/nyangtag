# 냥태그

고양이 밈 GIF로 하는 최대 8:8 파티 게임. 얼음땡·총싸움·웨이브 생존·클래스 점령전, 브라우저만 있으면 PC·폰 다 됩니다.

https://creepereye1204.github.io/nyangtag/

## 플레이
- **빠른 대전**: 코드 없이 공개방(QM01~QM06)에 자동으로 들어가요. 없으면 내가 방을 열고, 2명 이상 모이면 20초 뒤 자동 시작
- **방 만들기** → 4자리 코드나 초대 링크를 친구한테 보내기 → 친구는 코드 입력 후 **참가**
- 로비에서 인원(1:1 ~ 8:8), 팀, 맵을 고르기. 빈 자리는 봇이 채움
- **봇이랑 연습하기**로 혼자도 가능

## 모드
- **얼음땡**: 술래잡기 + 숨바꼭질 (아래 규칙)
- **냥냥 총싸움**: 물총 팀 데스매치. 상자에서 산탄·기관·저격 물총 줍기, 털뭉치 폭탄
- **로봇청소기 습격**: 박스헤드식 끝없는 웨이브 생존(협동). 연속으로 부수면 콤보 배율(최대 ×10), 웨이브마다 무기 해금(산탄 → 기관 → 냥 바주카 → 저격), 5웨이브마다 왕청소기 보스, 바리케이드, 쓰러진 동료 옆에 서면 부활
- **냥버워치**: 방석냥(탱커)·돌격냥·저격냥·츄르냥(힐러) 중 골라 가운데 점령 지점 100% 먼저

## 맵
한옥 야시장(밤·청사초롱 조명) · 냥냥 초등학교(교실·음악실·과학실·급식실·운동장·체육관) · 할로윈 호박밭(밤·유령 저택·묘지·옥수수밭) · 우주정거장 냥-7(정전·비상등·반응로·온실) · 우리 집 · 캣카페 · 눈 덮인 숲 · 여름 해변 · 고양이 마을(오픈월드). 로비 맵 카드에 실제 배치 미리보기가 나와요. 캣카페/숲/해변/할로윈은 시드 고정 절차 생성이라 방장과 손님이 같은 맵을 봅니다.

## 규칙
- 술래팀이 닿으면 얼음, 같은 팀이 닿아 주면 땡 (라운드당 2번까지, 3번째는 꽁꽁 얼음)
- 도망팀이 전부 얼면 술래팀 승, 끝까지 버티면 도망팀 승. 4라운드, 술래 교대
- 풀숲·이불·상자·차 밑에 숨으면 상대에게 안 보임. 가만히 있으면 더 안 들키고, 숨어서 움직이면 부스럭거려 잘 들킴
- 봇도 벽 너머나 먼 곳은 못 보고, 숨은 고양이는 가까이 와야 찾음

## 스킬 · 아이템
- 술래: 냄새 추적(숨은 고양이는 근처에 냄새 구름만), 덮치기(빨간 부채꼴 예고 후 돌진, 빗나가면 헛방)
- 도망: 털뭉치 트랩, 캣닢 가속, 들키는 순간 깜짝 가속
- 아이템 상자(7초마다 다시 생김, 최대 3개 보관): 보호색 · 블럭 쌓기 · 생선(쿨타임 초기화)

## 랭크 · 채팅
롤처럼 아이언 IV → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아몬드 → 마스터 → 그랜드마스터 → 챌린저. 이기면 +LP, 지면 −LP, 활약 보너스와 상대 티어 보정이 있고 봇 연습은 절반만 반영. 기록은 이름별로 기기(localStorage)에 저장되고, 전체 랭킹은 온라인에서 만난 사람끼리 랭킹표를 주고받아 합칩니다(서버 없음). 로비·게임 중 채팅(Enter 또는 ), 말풍선, 기본 욕설 가림.

## 조작
- PC: WASD/방향키 이동 · Space 대시 · Q/E 스킬 · R 아이템 · T 멘트 · Enter 채팅 · M 소리 · 전투 모드는 마우스 조준·클릭(또는 F) 발사
- 폰: 왼쪽 화면 드래그 = 조이스틱, 오른쪽 버튼들, 전투 모드는 자동 조준 + 발사 버튼 (진동 지원)

## 고양이
그림 고양이 4종 + 초록 배경(크로마키) 고양이 밈 60개 + 고양이 밈 GIF 480여 개, 또는 아무 GIF 주소나 붙여 넣기. 초록 배경 GIF는 게임에서 초록이 자동으로 지워집니다 (ImageDecoder 지원 브라우저).

## 구조
- `core.js` 맵·규칙·스킬·봇(A* 길찾기, 시야) — 방장 브라우저가 시뮬레이션. `TUNE`에 밸런스 수치
- `main.js` 화면·효과·소리·입력·로비·랭크·온라인 (PeerJS/WebRTC, 서버 없음)
- `gifs.js` 고양이 GIF 목록

[Releases](https://github.com/creepereye1204/nyangtag/releases)에서 배포 버전별 변경 내용을 볼 수 있어요.

## 조작 · 시점 · 그래픽
